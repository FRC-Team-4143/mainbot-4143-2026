# chargedup (dashboard web app)

Charged Up (2023) dashboard, served off the RoboRIO by `DashboardBridge.startWebServer()`, paired
with `frc.robot.subsystems.chargedupobserver.ChargedUpObserver`. Tables `/ChargedUp/ToRobot` and
`/ChargedUp/ToDashboard`, port `5803`.

See `../deepspace/README.md` for how these observers work and how to add another year's.
